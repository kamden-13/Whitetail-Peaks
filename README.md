# 🦌 WHITETAIL PEAKS

Retro Realistic Hunting Game — Tecmo Bowl Style

A full playable hunting game inspired by Hunter: Call of the Wild, with chunky retro pixel graphics.

## 🎮 Controls
- **WASD** = Move
- W = Up
- A = Left
- S = Down
- D = Right
- **SPACE** = SHOOT
- Shift = Crouch / Sneak
- C = Deer Call
- R = Reload

## 🏆 How To Play
- Harvest 3 Whitetail Bucks to win
- Follow tracks, watch the wind
- Use deer call (C) to lure them
- Manage ammo and stamina

## 🚀 Play It
Open `index.html` in any browser — no install needed.

## 🛠️ Tech
- Pure HTML / CSS / JavaScript
- Canvas pixel rendering
- No dependencies
